## Заблокировано и почему

1. **Postgres-тесты не прогонялись.** Docker выключен; тесты пропускаются без `TERROIR_PG_TEST_URL`. Код общий с SQLite, миграция — того же содержания. Проверка: `make up && make test-pg`.
2. **Dockerfile и compose не собирались** — по той же причине.
3. **Реальный LLM не вызывался**: ключей нет (так и задумано). openaicompat покрыт тестами на httptest.
4. **CI не запускался**: push запрещён.
5. **PWA не прокликан в браузере**: проверены отдача файлов, `node --check` и API. Service worker и установка на телефон работают только по https или с localhost.
