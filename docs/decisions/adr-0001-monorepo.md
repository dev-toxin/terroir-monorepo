# ADR-0001: Monorepo

## Status

Accepted

## Context

Terroir разрабатывается solo-разработчиком. Backend, frontend и infra тесно связаны.

## Decision

Используем приватный монорепозиторий для приложения:

```text
backend/
frontend/
infra/
docs/
```

Публичный landing находится отдельно в `terroir-site`.

## Consequences

Плюсы:

- Проще синхронизировать изменения API и клиента.
- Одна проектная память.
- Проще локальный запуск.

Минусы:

- Нужно следить за структурой.
- CI/CD позже должен уметь запускать части проекта отдельно.
