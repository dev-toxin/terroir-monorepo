# B2C features

## MVP

- Сканирование этикетки.
- Распознавание текста через OCR.
- LLM-парсинг этикетки в JSON.
- Сохранение вина в цифровой погреб.
- Дегустационные заметки.
- Базовый AI food pairing.
- История сканов.

## Post-MVP

- Совместные погреба.
- Deep Linking для шаринга винных сетов.
- Лента активности друзей.
- Сканирование винных карт ресторанов.
- Винный туризм и гиды по винодельням.
- Рекомендации российских автохтонных сортов.

## Принцип UX

Пользователь должен добавлять вино за 1 фото, без ручного заполнения длинных форм.
