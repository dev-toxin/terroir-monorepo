# B2B features

## Цель

Создать self-service SaaS для виноделен, винотек и дистрибьюторов без ручных продаж на старте.

## Базовые B2B функции

- Личный кабинет бренда.
- Загрузка каталога вин.
- CSV/Excel импорт прайсов.
- Верификация карточек вин.
- Размещение ссылок «Где купить».
- Интеграция остатков дистрибьюторов.

## Analytics as a Service

- Спрос по регионам.
- Популярные сорта.
- Популярные стили вина.
- Частотность сканов брендов.
- Динамика интереса к автохтонам.

## AI для B2B

- Генерация коммерческих предложений для ресторанов.
- Описание вин для карточек.
- Нормализация прайсов.
- Классификация вин по стилю и вкусовому профилю.

## Ограничение

B2B не входит в первый MVP, но архитектурно учитывается с первого дня.
