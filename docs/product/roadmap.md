# Terroir roadmap

## Phase 0 — Foundation

Цель: подготовить монорепозиторий, инфраструктуру и архитектурную память.

- Self-hosted PostgreSQL + pgvector.
- Go backend skeleton.
- Flutter app skeleton.
- Базовые документы продукта и архитектуры.
- Landing на `terroir-app.com`.

## Phase 1 — B2C MVP

Цель: первая полезная версия для пользователя.

- Регистрация/профиль.
- Сканирование этикетки.
- OCR -> LLM -> структурированный JSON вина.
- Создание карточки вина.
- Цифровой погреб.
- Дегустационные заметки.
- Базовый food pairing.
- Лимиты Freemium.

## Phase 2 — Beta

Цель: улучшение удержания и качества данных.

- История сканов.
- Улучшенная нормализация вин.
- Поиск похожих вин через pgvector.
- Импорт/экспорт погреба.
- Публичный share вин/сетов.
- Аналитика использования.

## Phase 3 — Premium B2C

Цель: монетизация B2C.

- Совместные семейные/клубные погреба.
- Расширенный анализ винных карт ресторанов.
- Безлимитные сканы.
- Персональные рекомендации.
- Deep Linking для шаринга.

## Phase 4 — B2B SaaS

Цель: self-service модель для виноделен и дистрибьюторов.

- Кабинет бренда.
- Загрузка прайсов CSV/Excel.
- Верификация карточек вин.
- Кнопка «Где купить».
- Генератор КП для ресторанов.
- Аналитика спроса.

## Что не делаем в MVP

- Полный realtime.
- Полноценный B2B-кабинет.
- Сложные социальные механики.
- Собственная платежная инфраструктура без validated demand.
